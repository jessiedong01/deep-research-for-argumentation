\section{Problem Formulation}
\label{sec:problem}

\paragraph{Problem:} Given a motion $m$ (e.g., ``The U.S.\ Federal Reserve should prioritize maintaining high interest rates over stimulating growth''), the goal is to generate an argumentative report $R$, which takes a position on the motion, argues for its position with claims, and anchors each factual claim to its source retrieved from the web. We define a good report as one that is (i) \emph{decisive} (takes a single position and argues for it), (ii) \emph{grounded} (each claim cited is supported by its source, known as verifiability \citep{rashkin2023ais, liu2023verifiability}), and (iii) \emph{connected} (the claims make a coherent case rather than a list of facts).

\sys{} performs its research by constructing a directed acyclic graph $G = (V, E)$, with a single root node $r$, whose question is $m$. Each node $v \in V$ has a question $q_v$, a format for the expected answer $f_v$, an answer $a_v$, and a set of sources $S_v$. There is an edge $(u, v) \in E$ if the question $q_v$ is a sub-question of the question $q_u$. For leaf nodes $v \in V$, the answer is obtained by retrieval, $a_v = \textsc{Answer}(q_v, S_v)$, with $S_v$ being the documents we retrieved. For a parent node $u \in V$ with children $C(u)$, the answer $a_u$ is obtained by composition,
\begin{equation}
a_u = \textsc{Compose}\big(q_u,\ \{a_v : v \in C(u)\},\ \kappa_u\big), \qquad S_u = \textstyle\bigcup_{v \in C(u)} S_v,
\label{eq:compose}
\end{equation}
where $\kappa_u$ are the composition instructions for how to combine its children's answers. The report is written from the answered graph, $R = \textsc{Write}(m, G)$.

A report can be grounded only if its citations stay correct through every composition step. The provenance of a citation is considered valid only if all citations made along the way are correct. If $\mathrm{cite}(a_v)$ indicates the set of (claim, source) pairs in $a_v$, then composition preserves provenance if every (claim, source) pair that $a_u$ borrows from a child is one the child itself contains. Thus, any citation can be traced through the graph all the way to the original source leaf. \Cref{sec:citations} will quantitatively assess the provenance preservation in the pipeline, and pinpoint where failures occur.
